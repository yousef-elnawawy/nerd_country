# الجمهورية النيردية المتحدة

> موقع إلكتروني رسمي للجمهورية النيردية المتحدة — منصة رقمية متكاملة تمثل مجتمعاً افتراضياً يضم أكثر من 500 مليون مواطن نيردي في مجال التكنولوجيا.

## 🏛️ نبذة عن الموقع

الجمهورية النيردية المتحدة هو مشروع رقمي طموح يهدف إلى بناء مجتمع افتراضي عربي رائد في مجال التكنولوجيا. تم تأسيس الموقع رسمياً في عام 2026، ويعمل كمنصة رسمية تعرض بنية الجمهورية الافتراضية من خلال تصور فني وإبداعي يضم وزراء ومؤسسات ووزارات تخيلية تعمل على خدمة المواطن النيردي.

## 🚀 تشغيل المشروع محلياً

### المتطلبات المسبقة
- **Node.js** >= 18
- **npm** أو **yarn** أو **pnpm** أو **bun**

### خطوات التثبيت

```bash
# 1. استنساخ المستودع
git clone https://github.com/joo-n/nerd.git

# 2. الانتقال إلى المجلد
cd nerd

# 3. تثبيت الاعتماديات
npm install

# 4. تشغيل خادم التطوير على المنفذ 3001
npm run dev
```

افتح [http://localhost:3001](http://localhost:3001) في متصفحك.

### الأوامر المتاحة

```bash
npm run dev      # تشغيل خادم التطوير
npm run build    # بناء المشروع للإنتاج
npm start        # تشغيل الإصدار الإنتاجي
npm run lint     # فحص الأكواد
```

## 🎨 نظام التصميم (Kinetic Noir)

المشروع يستخدم نظام تصميم مخصص يسمى **Kinetic Noir** يتميز بـ:

- 🎨 **لوحة ألوان عالية التباين**: خلفية داكنة مع لمسات حمراء نابضة
- 🔠 **Typography**: Montserrat للعناوين + Inter للنصوص
- 📐 **Layout**: شبكة 12 عمود (ديسكتوب) و 4 أعمدة (موبايل)
- 📱 **Shapes**: زوايا حادة لجميع المكونات
- ✨ **Elevation с**: طبقات لونية بدلاً من الظلال
